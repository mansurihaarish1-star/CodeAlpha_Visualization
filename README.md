# 📊 Data Visualization Project

## 📌 Project Overview

This project focuses on transforming raw sales data into meaningful visual insights using Python visualization libraries.

The project analyzes sales performance across products, regions, and years through charts, graphs, and statistical visualizations to support data-driven decision-making.

---

## 🎯 Objectives

* Transform raw data into visual representations
* Identify sales trends and patterns
* Compare product and regional performance
* Create clear and impactful visualizations
* Build a portfolio-ready data visualization project

---

## 🛠️ Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📂 Dataset Information

The dataset contains sales-related information including:

* Order_ID
* Product
* Region
* Units_Sold
* Unit_Price
* Year

A new column named **Total_Sales** was created using:

Total_Sales = Units_Sold × Unit_Price

---

## 📊 Visualizations Created

### ✅ Sales by Product

A horizontal bar chart comparing total sales generated by different products.

### ✅ Sales by Region

A bar chart showing regional sales performance.

### ✅ Sales Trend Over Years

A line chart representing yearly sales growth and trends.

### ✅ Units Sold Distribution

A histogram analyzing the distribution of units sold.

### ✅ Price vs Total Sales

A scatter plot showing the relationship between pricing and sales.

### ✅ Correlation Heatmap

A heatmap identifying relationships between numerical variables.

---

## 📈 Key Insights

* Certain products generate significantly higher revenue than others.
* Some regions contribute more to overall business sales.
* Sales trends reveal business growth patterns over time.
* Pricing influences sales performance and revenue generation.
* Correlation analysis helps understand relationships between sales metrics.
